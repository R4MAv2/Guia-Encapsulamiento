## Guia Algoritmos y Programacion 1

Bienvenido! Este repositorio esta creado unica y exclusivamente con el fin de demostrar los proyectos realizados en la materia de algoritmos y programacion 1 (AyP1) En la universidad nacional tres de febrero (UNTREF)

## Guia Arreglos

En esta guia encontraras ejercicios de la materia, en este caso ejercicios para practicar encapsulamiento, una base fundamental de POO, tales como, cerradura, notas, ticket, caja de ahorro, etc.
